# Sample Audio

To test the application, you can download CC-licensed clips of bird calls (e.g. from Xeno-canto) and place them in this directory. 

*Note: For legal reasons, no audio files are redistributed in this repository. All sample audio files have been excluded.*

Please respect the recordists and the specific licenses (e.g. CC BY-NC-SA 4.0) attached to each clip you download.
